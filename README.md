# LurkBD Agent

Voice-first Android companion for daily accounts (**হিসাব**), shop credit & stock, **study (পড়াশোনা)**, medicine reminders, five daily prayers, and Sehri/Iftar alarms — primarily in Bangla.

## Docs

- **[Full product plan](docs/LURKBD_AGENT_PLAN.md)** — modules, voice architecture, tech stack, delivery phases  
- **[Design mockups](docs/design/)** — Home, হিসাব, Shop, Study, Reminders, Voice  

## Modules (short)

**হিসাব** · দোকান · **পড়াশোনা** (ক্লাস/পড়ার রুটিন, নোট, স্ক্যান, রেজাল্ট, অ্যাসাইনমেন্ট) · ওষুধ · ইবাদত · Voice

## Design direction

Deep teal (`#0B4F4A`) · Soft sand (`#F7F3EC`) · Warm gold (`#C4A35A`) · Bangla-first typography · Floating mic on every screen  

## Status

Product plan and UI mockups. Implementation starts with Kotlin + Jetpack Compose (P0 → P1 হিসাব → P2 Voice Core).
